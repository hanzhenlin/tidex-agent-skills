# 🚀 Tidex Agent Skills

> 面向工业级软件工程的高质量 AI Agent 技能聚合库（Curated Agent Skills for Software Engineering）。  
> 致力于消除「多 Agent 拼出来的半成品屎山」，建立人机协作规范、单轨彻底改造、5点一线全链路雷达扫描与端到端闭环交付。

---

## 🌟 核心理念与亮点

- **🧩 极致自包含（Self-contained）**：每个技能内聚所有规约与生成器，无需复杂的外部模版依赖，开箱即用。
- **🌐 全端智能识别**：一套技能，自动打通 **Claude Code**、**Codex**、**ZCode**、**Workbuddy**、**Cursor / Roo Code / Cline** 等主流 Agent 工具。
- **⚡ 杜绝双轨屎山**：坚决推行「单轨彻底改造」——改造即替换，严禁擅自保留 `@Deprecated` 转发层与参数兼容胶水层。
- **✂️ 文档脱水瘦身引擎（doc-slim）**：坚决四删四留，拒绝裸编号指针跳转，核心断言就地自闭环，大幅节省 Agent 上下文 Token 并杜绝全仓死链。
- **🔒 幂等与无损管理**：安装脚本自动检测、防重复安装、软链接实时同步更新，并提供一键纯净安全卸载。

## ⚡ 快速安装指引

### 方式 A：主流安装法（两步搞定）

在终端中执行以下命令：

```bash
# 1. 克隆本仓库到本地
git clone https://github.com/tidexai/tidex-agent-skills.git

# 2. 进入目录并执行一键安装
cd tidex-agent-skills
bash install.sh
```

脚本将自动执行雷达扫描，将技能以软链接方式挂载到您电脑上所有已识别的 Agent 宿主目录（如 `~/.agents/skills`、`~/.zcode/skills` 等）。

---

### 方式 B：特定项目挂载（团队工程共享）

如果希望仅将技能部署在某个特定开发项目的根目录下（随项目代码库生效）：

```bash
bash install.sh --target /path/to/your/project/.agents/skills
```

---

### 方式 C：安全卸载（纯净无残留）

如果需要卸载或清理挂载：

```bash
# 执行卸载
bash install.sh --uninstall

# 或直接运行快捷脚本
./uninstall.sh
```
> **安全承诺**：卸载程序只会移除指向 Tidex 的软链接，绝对不会触碰或删除您原本安装的其他自定义技能。

## 💡 日常协作流水线

在日常开发工作中，推荐按如下标准化流水线与 Agent 配合：

```text
[新需求从0到1] ────────►  /code-start-feature  (雷达扫描 -> 极简规划 -> 单轨实现)
                               │
[已有功能修补/适配] ──►  /code-refine-feature (快修直达 / 契约门禁确认)
                               │
                               ▼
                        [代码自检编译]
                               │
                               ▼
                        [生成提交说明] ──► 开发者本人 Commit / Push
                               ▲
                               │ 遵循规范与节奏
┌──────────────────────────────┴──────────────────────────────┐
│                    code-repo-steward                         │
│   • 项目定期体检排毒         • 协作规范就地沉淀 (AGENTS.md)    │
│   • 预定任务清单防注水管理    • 核心文档脱水瘦身 (doc-slim)     │
└─────────────────────────────────────────────────────────────┘
```
